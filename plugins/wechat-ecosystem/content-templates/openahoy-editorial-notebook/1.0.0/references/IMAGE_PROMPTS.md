# 配图与可直接填充的提示词

本套可选风格：细腻纸张质感的水彩/水粉编辑插画，暖米白、深青绿与少量珊瑚橙，真实光照与清晰主体。用户指定照片、科学图或其他风格时采用其要求，不把本套风格强加给所有文章。

## 封面提示词模板

为文章《{文章标题}》生成原创编辑插画，画面比例{封面比例}。文章的具体主题是{事实与主旨}，可视化为{主要场景与主体}；材质{材质}，配色{配色}，光线{光线}。封面默认出现准确中文短标题“{短标题}”；所有标题字和最重要的主体完整放在最左侧、与画面高度同宽的1:1方形内，留约6%安全边距。右侧自然延展同一场景，完整宽图也有清晰叙事。除明确所需标签外不要其他文字或水印。不要在包含短标题的提示词中再写no text。生成单张完整画面，不拼选项、不加样机边框。若用户要求无字，则去掉短标题要求并明确无字。

## 正文图提示词模板

为小节“{小节主旨}”生成一张{比例}的解释图/场景插画。它必须帮助读者理解{关系或机制}，清晰呈现{主体、连接及准确标签}。延续{材质与配色}但不机械重复封面。标签只用{逐项准确短文本}，手机宽度可读。真实结构/参数按{一手证据}绘制；概念示意明确标为示意，不将美术图冒充实验结果。不要无意义装饰、第三方标识、假统计或模糊占位文字。

生成前查看真实参考图；生成后查看原图，核对中文字、对象结构、信息准确性和左方裁切。发现错字用图像工具修正，不凭成功返回就认为视觉达标。每幅图围绕该文内容单独创作，不直接复用本包演示图充当新闻照片。

微信传输图按本号现行平台技术标准处理（当前正文图片小于1MB）；保留原件，用适合的副本编码并实际核大小。尺寸、风格与总图片数量没有本模板自建业务额度。封面宽图与1:1使用同一原图的不同选区，不生成两个互不一致的封面。
