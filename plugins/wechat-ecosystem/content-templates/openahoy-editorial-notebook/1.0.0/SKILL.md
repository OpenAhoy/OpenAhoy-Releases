# 灵感手记 · 1.0.0

OpenAhoy 维护的通用创作示例，不是腾讯认证，不是事实来源，也不提供发文或自动化授权。

依次完整读取 references/WRITING.md、references/IMAGE_PROMPTS.md、references/FORMATTING.md、references/EXAMPLE_PROMPTS.md、example/article.md、example/source.html、example/article.css 和 example/metadata.json；查看 assets/cover.jpg 与 assets/process.jpg，理解真实材质、层级及封面安全区。所有这些都是本包材料。不要只读此入口就开始制作。

在 OpenAhoy 内选择模板后，通用平台 Skill 会通过 own.templates.read 读取精确版本。无需向每个项目重复安装此 Skill。独立下载包可按宿主正式 Skill 安装机制采用；下载本身不等于安装、生效或绑定。

以本号当前有效规则及本人当前要求为先；模板仅补充未约定细节。原作者、主题、已有自定义要求保持。只用于新创作，既有稿件、在途内容、定时任务与发布委托不因应用模板而改变。
