# 灵感手记 · 1.0.1

OpenAhoy 维护的通用创作示例，不是腾讯认证，不是事实来源，也不提供发文或自动化授权。

依次完整读取 references/WRITING.md、references/VISUAL_METHOD.md、references/IMAGE_PROMPTS.md、references/FORMATTING.md、references/EXAMPLE_PROMPTS.md、references/CHANGES.md、example/article.md、example/source.html、example/article.css 和 example/metadata.json；查看 assets/cover.jpg 与 assets/process.jpg，理解真实材质、层级及封面安全区。所有这些都是本包材料。不要只读此入口就开始制作。

视觉创作先从文章具体读者问题、真实主体/关系/变化和依据确定每张图的信息任务，再选场景、实物/界面、机制、对照、流程或数据表达。实际提示词必须包含目标、依据、可辨主体、动作/关系、准确标签及完整构图，不能只换标题和风格。各图有分工，材质/光线服务内容，左安全区不等于右侧留空；不设固定风格、图数或细节数量。方法例和本包演示都不能代替实际生产者的事实核对。

在 OpenAhoy 内选择模板后，通用平台 Skill 会通过 own.templates.read 读取精确版本。无需向每个项目重复安装此 Skill。独立下载包可按宿主正式 Skill 安装机制采用；下载本身不等于安装、生效或绑定。

以本号当前有效规则及本人当前要求为先；模板仅补充未约定细节。原作者、主题、已有自定义要求保持。只用于新创作，既有稿件、在途内容、定时任务与发布委托不因应用模板而改变。
