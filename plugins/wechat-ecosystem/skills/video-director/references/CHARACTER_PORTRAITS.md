# 人物卡头像取景

人物总览只选明确登记的独立正面人头。需要生成时，按项目与人物版本读出已确认的正面参考原图，将该图作为身份参考交给本次授权的生图工具。待确认的新图登记为候选，原参考和现用版本按原项目流程保留。

## 生成交接模板

把括号里的内容替换为当前人物真实特征。从本人物已确认的参考中提取脸型、发际线、发量和走势。参考中有刘海、眼镜、帽饰或其他自然遮挡时一并保留。

> 以附带的已确认正面原图为身份参考，生成「[人物名 / 形态]」的白底独立单人正面人头图。保留 [原脸型、五官比例、真实遮挡] 与 [原发际线、发量、长短、走向、配饰]。从额头或自然遮挡处至下巴完整置于画面，长脸、圆脸、宽脸和窄脸保持可辨。给相邻人物卡安排同组近景的视觉份量，个别长脸可整头等比缩小。让左右留白和头发走向自然，长发可以延至侧边或下缘，高发髻、蓬发或帽饰可以延至上缘。出框处的发丝连贯延伸。画面保持纯白，标题姓名由产品另排。

## 选用、导入与预览

先把本组长脸长发、圆脸短发、高发髻及其他角色放到实际人物卡并排看。脸应有近景的协调感，同时保留每张脸原比例及可见的完整下巴。按角色微调整个图像的等比取景。发型可沿媒体边缘自然出框，画面中的发丝连续。避免用统一脸框、像素高度、瞳距、面积或发顶到下巴百分比代替逐图判断。姓名栏由卡片固定在媒体下方。沿原路径确认素材身份与版本。

把白底专用图原件记录在已有 schema 3 索引的 `use: "face"`、`appearance.group: "base"`、`appearance.view: "head_front"`、`appearance.format: "individual"`，并记录原件相对路径与 SHA-256。仅标准形态的独立正面人头可设置 `portrait_frame`。源自全身图的裁切派生、特定作品版本与不含可见人脸的头模继续使用对应原槽。

可选的 `portrait_frame` 是经逐图目视校准的**显示窗口**。坐标以图像正常显示方向的左上为原点，横、纵分别使用原图宽、高的 0 至 10000 单位。宽、高为正且窗口须在原图内。示例片段 `"portrait_frame":{"x":250,"y":550,"width":9500,"height":8000}` 仅说明字段，实际数据按本图取景。卡片以等比缩放包含该窗口，必要时显示周边余量，裁切只在卡片媒体边缘。不提供显示窗口时，总览完整呈现登记的头像原图。显示窗口与实际裁切件的 `crop` 字段独立。

用「形象资产库 → 管理 → 导入索引」预览并登记，或以原 `character_import_preview` 和 `character_import` 同一摘要与预览修订完成。导入预览区分已校准取景和头像完整原图。登记后返回总览核对并排效果，点开可读原图。本轮若调整原件版本或已登记取景，按原索引版本规则使用新的版本 ID，保留原文件和历史。
