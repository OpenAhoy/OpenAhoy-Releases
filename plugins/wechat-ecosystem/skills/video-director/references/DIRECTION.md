# 分镜、镜头与提示词

## 从画面决定资产

| 镜头要求 | 资产与模式 |
| --- | --- |
| 单镜头中两个构图都要准确出现 | 生成/选取同画幅的首尾图，让姿态、道具和环境在两张图之间有可实现的变化。提交为首尾帧。 |
| 要准确经过一张中间图 | 在该瞬间拆段。上一段用这张图作尾帧，下一段用它作首帧；让运动方向、视线、光向和动作相位相接。 |
| 多角度复用人物、场景、产品或色调 | 选清晰且职责互补的图，按顺序标作 `@图片1`、`@图片2`。一张做身份、一张做空间、一张做道具时，把责任写清楚。 |
| 概念探索，画面允许模型发挥 | 可用文生视频。把最重要的空间和动作写具体，成片再据实际画面优化。 |

多图用于提供视觉证据。近似素材、另一个版本的角色或方向冲突的场景会增加歧义。镜头时间轴与资产顺序分别写清。手机竖屏把关键动作放在中部可见区，并按目标平台为字幕和界面留位置。横屏让前景、中景、远景各承担明确作用。

## 把镜头词变成可见变化

- **机位和景别**：交代画面开始看见什么。用「低机位中景，桌沿占下方四分之一」之类的描述；最后交代画面停在哪个主体上。
- **运动**：推镜靠近主体并增加透视变化；横移揭示遮挡关系；环绕交代从哪侧、绕多大角度；摇摄从固定位置改变观看方向；拉焦明确前景和背景的焦点交接。单镜头先选一个主运动。需要不同机位时才切镜。
- **灯光和环境**：写光源方位、软硬、颜色及其在材质上的变化。写「左侧窗口的冷色天光沿金属边缘缓慢滑动」，避免用相互冲突的风格形容词。让雾、风、反光或影子服务于景深和动作。
- **表演和节奏**：用动词描述开始、变化、落点。时间码是节奏指令，复杂多个动作拆成不同镜头。
- **声音**：明确环境底声、同步动作音、台词出现时刻。有声任务只保留需要的声音层。品牌文字、字幕和精确标志适合后期叠加。

## 可直接改写的原创例子

**产品短片 · 多图参考 · 8 秒**

素材绑定：@图片1 用于录音机的外形与旋钮，@图片2 用于深色胡桃木桌与窗光。0–2 秒，低机位近景从旋钮侧面开始，左侧窄窗光勾亮金属边缘。2–6 秒，镜头平稳右移，前景线缆经过焦外，焦点落在转动的磁带轮。6–8 秒，镜头自然停稳，让整台录音机和桌面都能辨认。声音以室内底噪和磁带轮轻转为主，字幕后期添加。

**叙事转场 · 严格首尾帧 · 6 秒**

第一张图锁定昏暗楼道入口，第二张图锁定推门后被晨光照亮的工作间。镜头沿视线方向慢推，起初门框保持在两侧，门向内打开时露出工作台。光从狭窄门缝逐步扩到地板，最后在第二张图的构图上停稳。只保留门轴和脚步声。若中途必须严格出现某个门缝构图，单独制作该图并在此处拆段。

细节、时长和素材遵循 [Seedance 2.5 官方提示词指南](https://docs.volcengine.com/docs/ark/seedance-2-5-prompt-guide?lang=zh) 及 [创建任务 API](https://docs.volcengine.com/docs/ark/create-video-generation-task-api?lang=zh)。
