# 制作稿约定

同一轮分别整理歌名、Styles、歌词、Exclude 及设置。Styles 用简短英文表达可听见的配器、速度与律动、人声、起承转合和收束。排除项另列。标题待定时用原歌名或标明暂名。按原词和用途决定纯音乐、完整 Custom 或短描述。固定歌词走 Custom。纯词用于展示与复制，供应商演唱输入可用如 `[Verse]`、`[Chorus]` 及少量表现提示。

歌词修订保留用户指定的人称、Hook、未要求改的句子、分段和结尾。先检查表达、情绪和可唱性，再处理韵脚；有旋律或参考演唱时按实际乐句、落拍、重音与延音。词、风格、设置与演绎分别改动。已确认的词稿仅改用户指定范围。对原词已有的引语和署名沿原稿保留。

Custom 将 Title、Styles、演唱输入、Exclude 分别映射到 `title`、`style`、`lyrics`、`negative_style`。纯音乐发送 `instrumental: true`，保持人声约束一致。Simple 使用 `description` 的实际工具契约。模型、声音、时长和数值控制采用本轮真实工具支持及用户选择，0 是有效数值。已有模型偏好应复用。无法精确锁定时长或音符时，将其作为目标，按真实成片验收。
