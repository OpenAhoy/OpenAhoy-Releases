# 小红书 · 正常浏览器图文通路

本适配使用插件隔离的标准Chrome正常网页，并非官方发布API。本人在官方页面扫码与完成验证码；不索取/输出Cookie、密码、验证码或二维码，不复制其他浏览器资料，不使用私有签名、隐藏接口或指纹伪装。

绑定入口在内嵌页面选择「小红书」；官方扫码实际显示在独立Chrome窗口。后台确认真实用户ID和昵称后自动刷新顶部账号卡片。新账号使用独立会话，不覆盖旧号；所有业务指定`xhs.connections.list`返回的`connection_id`。本机未具备运行时时如实提示，不自动安装系统浏览器或改变网络/权限。软件安装、登录绑定与真实发表分别核验。

创作前用现有`own.projects.read`读取本号effective项目AGENTS/Skills和创作偏好，未关联不阻正常创作。按本次用户委托生成全新标题、正文、实际图片序列和可选话题，不把公众号HTML当笔记，不给所有用户套私人主题/比例/文风。图片顺序按输入数组保留；不自建字数/图数/大小业务配额，实际平台页面限制、审核和错误照实处理。

- `xhs.profile.read`：本号真实资料；`xhs.notes.list`：本号当前页面可见笔记，返回完整性标签，不冒全部历史。
- `xhs.notes.read`：指定本号笔记ID，读取实际作者、标题、正文和详情图片顺序。登录态可读不等于公开可读。
- `xhs.notes.publish`：当前委托覆盖真实发表时，以原`attempt_id`、标题、正文、有序图片绝对路径及SHA256发起一次。图像输入是同号本次选定原件，不自动有损重编码或截断文本。保存UNKNOWN先于远端上传/提交，未知不换键、不重发。仅本人另行明确接受该原任务的重复风险时，可指定一次新的recovery_id接续原请求；同一恢复ID重复调用不再次提交，旧未知记录保留，不自动生成恢复批准。
- `xhs.attempt.status`：只读本地原请求；`xhs.notes.readback`：查询原提交结果与原笔记ID/URL，独立读回实际内容、作者和图片。提交、审核中、本人可见、公开链接可见分开报告；没有原ID或结果歧义保持未知，不因页面跳转声称成功，不扫描全部历史作为发表前置。

账号登录/验证码由本人在官方页面处理；已经明确委托的图文不再添加审稿许可或逐步批准。本人偏好、官方兼容条件与真实授权保持分离。当前适配不自动点赞、回复、关注、私信、生产调度或视频发布。
