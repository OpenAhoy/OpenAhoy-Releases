# 制作、修改与下载个人生产配置

本指南随 OpenAhoy 同一 Skill 安装，配置格式版本与插件版本独立。当前仅支持微信公众号。它描述非秘密偏好，不授予绑定、发表、群发、定时任务或工具权限，不改变旧稿。

## 选择适合的入口

- 在同一内嵌管理页选中账号，点“快速创建配置”：以本号完整有效规则为起点，在“账号定位、写作方式、配图与排版、创作复查与交付、补充说明”五个分区中填写。分区切换保留未保存文字，也可用左右方向键、Home、End 切换。快捷文字可修改、追加或不选。原规则页未保存编辑及各号创建草稿分别保留。
- “保存到此公众号”沿原保存事务与历史，八字段完整独立读回后才显示完成。提交结果未知时接续原操作，不能换号或新建提交。并发版本变化保留填写，可明确选择用最新规则重新填写。
- “下载配置文件”生成点击时当前表单的完整快照，包括尚未保存的修改；不会隐式保存到本号。优先使用宿主正式文件下载能力。宿主没有提供该能力时，同一 app-only 桥可将非秘密快照独占写入本机 Downloads，完整读回 SHA 后才报告文件已保存。宿主明确拒绝或下载结果未知时不换通路，不外跳。
- 本机兼容导出使用安全唯一文件名，文件权限为仅本人读写；不覆盖已有文件。结果未知时按钮变为“查询上次导出结果”，沿原导出 ID 和冻结快照检查原文件，不新写。文件未找到时会明确说明，再次点击才下载当前填写。JSON 仍为同一 v1 格式；本机文件使用不透明收据元数据区分原账号，迁移加载只消费 JSON 正文，不迁移连接身份。
- “用配置文件填写”只将兼容文件填入创建草稿，供预览、修改，尚未保存。原“加载配置”则将所选文件直接保存到当前明确账号并完整读回，两者不同。

## Codex 帮助制作文件

先读取用户对目标、文风、配图和版式的实际要求。可用原生只读规则工具时，读取本号 effective manifest，再读取每个非空字段的全部 chunks，核对 Unicode 长度、UTF-8 字节及 SHA256。保留用户未要求更改的现有有效值；拿不到旧值时，只询问会影响覆盖结果的必要信息，不擅自以空串补齐旧规则。账号名称以内嵌页实际唯一可核显示名为准，不能把 connection_id 或 AppID 当作名称。

使用标准 JSON 库序列化 UTF-8 文件；优先无 BOM。对照随包 Schema 与本指南检查，交付文件并说明目标名、完整覆盖及空白语义。当前没有模型直接预填内嵌页的正式桥，不能调用 app-only 保存代替本人文件选择，不宣传无点击写入 UI。不安装 Node 或其他运行依赖来制作普通 JSON；现有环境能做的格式检查与最终内嵌 parser 验证分别说明。

可直接给 Codex 的请求：

> 根据我选中的公众号及以下偏好，帮我生成兼容 OpenAhoy v1 的非秘密配置文件。先读取可用的完整有效规则，保留我未要求改动的字段；缺少会导致覆盖的信息才问我。账号名使用内嵌页当前显示名。不要包含密钥、ID、机器路径、定时任务或权限，不代我保存或发表。生成后说明八项完整覆盖和空白清空语义，我会用“用配置文件填写”或“加载配置”带入。

## 格式合同

参考 [虚构示例](../templates/production-preferences.example.json)、[空白模板](../templates/production-preferences.blank.json)、[JSON Schema](../templates/production-preferences.v1.schema.json)。空模板尚未填写账号名，不能直接加载；八项空串都会显式清空，不代表保持或继承。

文件名建议为“账号名.openahoy.json”，一个 UTF-8 JSON 文件对应一个账号。根恰好五键：

- format 固定为 openahoy.production-preferences。
- schema_version 为数字 1。
- platform 固定为 wechat_official_account。
- account_name 为当前账号唯一可核显示名；它不是授权，也不能从文件选择连接。
- fields 恰好包含下表八个字符串键，允许空字符串。

|字段|内容|
|---|---|
|audience_topics|受众、领域、选题、参考信源、排除主题|
|author|希望使用的署名，不代表原创或认证|
|voice|文风、结构、表达习惯、希望避免的措辞|
|image_preferences|图片内容、来源、真实或生成偏好、版权与注明|
|visual_layout|用户选择的配色、字号、间距及图片比例|
|content_qa|创作后事实、来源和图文复查，不创建发表审批|
|delivery_publication|交付与普通发表偏好，不能替代当前有效委托|
|additional_notes|其他非秘密文本或 Markdown，不执行命令或脚本|

八项为本号完整覆盖。空串是显式清空，不能解释成继承或保持；继承导出是本次有效文本快照，动态继承关系不会随 JSON 迁移。需要继续继承时，在原规则设置页操作。保存保留原历史，不修改其他账号和平台默认。

禁止额外根键、缺少或未知字段、非字符串字段、重复 JSON 键、注释、尾逗号、无效 UTF-8/Unicode 和现存不支持的控制字符。不得放入 AppSecret、token、Cookie、密码、AppID、connection_id、绝对路径、权限、绑定状态、日程或插件环境配置。现存疑似秘密匹配无法穷尽所有秘密，制作方仍必须主动排除。Schema 只描述基础结构；重复键、编码、文本安全、秘密模式和当前账号唯一匹配由同一个运行 parser/上下文验证，Schema 不替代最终验证。

配置不能关闭微信真实接口约束，也不固定所有用户的文风、图像类型、比例、字数或信源名单。技术输入要求见随包 HTML 技术标准，个人选择与官方要求分别处理。文本不静默截断；现有分块处理不构成每日或配置业务额度。解析仍受本机内存等运行环境约束，失败如实报告。

未编辑的文件字段保留原字符串（包括 CRLF 换行）；浏览器文本框按标准显示为换行，手动编辑该字段后使用文本框的新值。下载、保存及读回均以当前字段字符串为准，不静默改写其他字段。
