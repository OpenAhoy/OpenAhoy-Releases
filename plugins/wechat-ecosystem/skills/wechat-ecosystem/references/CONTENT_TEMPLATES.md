# 官方创作模板

模板指Jiusera维护的可选创作材料，不是腾讯认证、事实来源、业务权限或额外发表许可。原账号、作者、主题、用户自定义及当前有效要求优先。读取失败时说明具体材料缺口，现有未采用模板的流程照常，不以模板服务问题阻断既有发表。

## 新创作如何读取

1. 选定真实账号后调用 `own.templates.read`：`{"view":"selected","connection_id":"原账号ID"}`。空templates表示未采用模板，沿本号原规则即可。多个模板引用按当前账号明确选择处理，发现同ID不同版本以最后引用为当前版本，不猜同名外部Skill。
2. 对已选引用调用 `view:manifest, template_id, version`，核对manifest_sha256等于本号引用；不静默换最新版本。`view:catalog`的templates列出页面当前推荐修订，archived_templates列出保留的历史版本。旧引用仍按原版本读取；只有本人主动采用新修订才变更本号引用。版本确实不存在时说明缺口，让用户在原页面选择，不自动覆盖配置或改用未选风格。
3. 按manifest的read_order逐文件调用 `view:part, template_id,version,manifest_sha256,file,index`。按索引组合全部base64块，核对每块SHA、总字节和文件SHA，UTF8解码。入口SKILL.md不等于完整材料，必须读写作、生图、排版、实际提示词、文章/HTML/CSS和许可。块大小仅传输边界，无自建总内容额度。
4. 图片按assets清单调用 `view:image`，同时传入template_id、version、manifest_sha256、file；工具返回实际MCP图像内容供查看，不把图片说明当作已经看过原图。需要本地副本时可按part组合全部二进制块，核对后保存在当前项目任务_local工作区；不要把base64值打印进聊天/日志。无图像查看能力时如实记录未查看，不假称视觉执行。
5. 本模板示例是演示，不作为新闻、事实或旧文章直接发表。依实际题材重新创作图片与全文，采用示例中的结构和视觉方法，不复制示例文冒充生产。具体技术处理和发表沿现有平台规则。

1.0.1增补内容驱动的视觉方法：已选此版本时，必须完整读取references/VISUAL_METHOD.md、IMAGE_PROMPTS.md与CHANGES.md，再依据实际文章确定各图目标/依据/主体关系/变化与构图。EXAMPLE_PROMPTS.md及演示图仍为1.0.0历史样例，不能声称已按新方法重做。安装、本人主动应用、生产时读取新材料及最终图像视觉验收分别核对，不因升级自动重做文章或替本人调度生产。

## 页面与更新

公众号设置→创作模板：同包样稿预览（包含完整宽封面与同图最左1:1）、下载标准Skill ZIP、明确选本号后一键应用。应用沿原begin/chunk/commit规则保存，读回完整八字段和继承关系；保留原作者/选题/自定义，只追加模板建议与精确版本引用。未保存编辑先留在原编辑页，不能覆盖；未知结果只查原保存。

新模板/模板更新随插件稳定版本发布，页面软件更新区检查并由本人一键发起软件升级。升级后模板卡显示当前随包版本及变更，已采用旧版本会提示新版本可用；应用由本人选择，不静默覆盖已有修改。下载不等于应用，预览不调用平台API。独立ZIP包含SKILL.md、references、assets、example和许可，example/complete.html可离线打开；它不含账号或个人配置。

写作规则包独立管理，见[润色已有文字](WRITING_POLISH.md)。模板卡、已选模板版本和账号偏好沿原规则保存。
